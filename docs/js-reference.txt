================================================================================
                       JAVASCRIPT FUNCTION REFERENCE
================================================================================

This document provides a quick reference for all JavaScript functions
used in the EngNotes project, organized by module.

================================================================================
                         THEME-MANAGER.JS
================================================================================

Functions:
-----------

setTheme(theme)
  Description: Sets the current theme and updates UI
  Parameters:
    - theme (string): 'light', 'dark', or 'pure-black'
  Returns: void
  Example:
    setTheme('dark');        // Switch to dark mode
    setTheme('pure-black');  // Switch to AMOLED mode

getTheme()
  Description: Gets the current theme name
  Parameters: none
  Returns: string - Current theme name
  Example:
    var theme = getTheme();  // Returns 'light', 'dark', or 'pure-black'

initTheme()
  Description: Initializes theme from localStorage
  Parameters: none
  Returns: void
  Note: Called automatically on script load

updateThemeButtons(activeTheme)
  Description: Updates theme button active states
  Parameters:
    - activeTheme (string): Theme to mark as active
  Returns: void

Variables:
  THEME_OPTIONS    - Object with theme constants
  THEME_STORAGE_KEY- localStorage key ('engnotes-theme')
  currentTheme     - Current active theme string

================================================================================
                         DRIVE-API.JS
================================================================================

Functions:
-----------

loadGoogleAPI()
  Description: Loads and initializes Google API client
  Parameters: none
  Returns: Promise - Resolves when API is ready
  Example:
    await loadGoogleAPI();
    // Now can make Drive API calls

fetchFolders(parentId)
  Description: Gets all folders within a parent folder
  Parameters:
    - parentId (string): Google Drive folder ID
  Returns: Promise<Array> - Array of folder objects
  Example:
    var folders = await fetchFolders('folder-id-here');
    // Returns: [{id: '...', name: 'Folder Name'}, ...]

loadFilesFromFolder(folderId)
  Description: Gets all files from a folder (cached)
  Parameters:
    - folderId (string): Google Drive folder ID
  Returns: Promise<Array> - Array of file objects
  Example:
    var files = await loadFilesFromFolder('folder-id');
    // Returns: [{id, title, type, fileName, driveUrl}, ...]

buildStructure()
  Description: Builds complete folder structure from Drive
  Parameters: none
  Returns: Promise<Array> - Complete data structure
  Example:
    var data = await buildStructure();
    // Returns: [{id, code, name, semesters: {...}}]

detectSemester(name)
  Description: Parses semester number from folder name
  Parameters:
    - name (string): Folder name to parse
  Returns: number|null - Semester number (1-8) or null
  Example:
    detectSemester('Sem 3');        // Returns 3
    detectSemester('3rd Semester'); // Returns 3
    detectSemester('Random');       // Returns null

detectUnitNumber(name)
  Description: Parses unit number from folder name
  Parameters:
    - name (string): Folder name to parse
  Returns: number|null - Unit number or null
  Example:
    detectUnitNumber('Unit 1');     // Returns 1
    detectUnitNumber('unit-2');     // Returns 2
    detectUnitNumber('Module 3');   // Returns 3

getDeptCode(name)
  Description: Gets department code from name
  Parameters:
    - name (string): Department name
  Returns: string - Department code
  Example:
    getDeptCode('Computer Science');  // Returns 'CSE'
    getDeptCode('Electronics');       // Returns 'ECE'

detectSemesterFromSubject(name)
  Description: Detects semester from subject name
  Parameters:
    - name (string): Subject name
  Returns: number|null - Semester number or null

buildSubjectData(folder, semNum)
  Description: Builds subject data with units
  Parameters:
    - folder (Object): Folder object
    - semNum (number): Semester number
  Returns: Promise<Object> - Subject data with units

Variables:
  API_KEY          - Google API key
  ROOT_FOLDER_ID   - Root Drive folder ID
  filesCache       - Cache for loaded files
  structureLoaded  - Flag for structure loaded
  DATA             - Main data structure
  DEPT_CODES       - Department code mapping

================================================================================
                         ADBLOCK-DETECTOR.JS
================================================================================

Based on: https://github.com/OddDevelopment/Simple-Adblock-Detector

Detection Functions:
--------------------

detectAdblock()
  Description: Main detection function (async)
  Parameters: none
  Returns: Promise<boolean> - True if adblock detected
  Example:
    var detected = await detectAdblock();
    if (detected) { showAdblockPopup(); }

outbrainErrorCheck()
  Description: Checks if Outbrain ad script is blocked
  Parameters: none
  Returns: Promise<boolean> - True if blocked

adligatureErrorCheck()
  Description: Checks if AdLigature is blocked
  Parameters: none
  Returns: Promise<boolean> - True if blocked

quantserveErrorCheck()
  Description: Checks if Quantserve is blocked
  Parameters: none
  Returns: Promise<boolean> - True if blocked

setIntervalCheck()
  Description: Checks if setInterval is tampered with
  Parameters: none
  Returns: Promise<boolean> - True if tampered

idCheck()
  Description: Checks if ad bait elements are hidden
  Parameters: none
  Returns: Promise<boolean> - True if adblock detected

Popup Functions:
----------------

showAdblockPopup()
  Description: Shows the adblock detection popup
  Parameters: none
  Returns: void
  Note: Checks localStorage for 'engnotes-adblock-dismissed' first

closeAdblockPopup()
  Description: Closes popup for current session
  Parameters: none
  Returns: void

dismissAdblockPopup()
  Description: Dismisses popup permanently
  Parameters: none
  Returns: void
  Note: Saves 'engnotes-adblock-dismissed' to localStorage

Detection Methods:
  1. Fetch-based: Attempts to load known ad URLs
  2. Timer check: Detects setInterval tampering
  3. DOM check: Creates bait elements with ad-related IDs

================================================================================
                         DATA STRUCTURES
================================================================================

DATA Structure:
---------------
[
  {
    id: string,           // Google Drive folder ID
    code: string,         // Department code (e.g., 'CSE')
    name: string,         // Department name
    folderId: string,     // Same as id
    semesters: {
      1: [                // Semester number
        {
          id: string,     // Subject folder ID
          code: string,   // Subject code
          name: string,   // Subject name
          folderId: string,
          semester: number,
          units: [
            {
              id: string,       // Unit folder ID
              name: string,     // Unit name
              number: number,   // Unit number
              folderId: string,
              isDefault: boolean // Optional
            }
          ]
        }
      ]
    }
  }
]

File Object:
------------
{
  id: string,           // Google Drive file ID
  title: string,        // File title (no extension)
  type: string,         // 'NOTES', 'QP', 'LAB', or 'TEXTBOOK'
  fileName: string,     // Full filename with extension
  parentFolder: string, // Parent folder name (optional)
  driveUrl: string      // Google Drive preview URL
}

================================================================================
                           HTML FILES OVERVIEW
================================================================================

The HTML files in deploy/ and deploy/pages/ have been refactored to use
the modular CSS and JS files. Each HTML file:

1. Links to CSS files in order:
   - themes.css (must be first - defines CSS variables)
   - common.css (shared styles)
   - Page-specific CSS (notes.css/textbooks.css/home.css)

2. Links to JS files in order:
   - theme-manager.js (must be first - sets theme before render)
   - drive-api.js (Google Drive functions)
   - navigation.js (UI rendering)
   - bot-protection.js (security)
   - Page-specific JS (notes-app.js/textbooks-app.js/home-app.js)

================================================================================
                              QUICK REFERENCE
================================================================================

To add a new CSS variable:
  1. Add to :root in themes.css (Light theme)
  2. Add to [data-theme="dark"] in themes.css (Dark theme)
  3. Add to [data-theme="pure-black"] in themes.css (AMOLED theme)

To add a new function:
  1. Determine which module it belongs to
  2. Add function with JSDoc comments
  3. Update this file-map.txt

To add a new page:
  1. Create HTML file in appropriate location
  2. Create page-specific CSS in css/
  3. Create page-specific JS in js/
  4. Include necessary shared modules
